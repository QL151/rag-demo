# 可选依赖：真实的 Chroma 向量数据库
#
# 为什么单独放一个文件？
#   早前在 Python 3.13 上装 chromadb 失败过（pip 报 from versions: none），
#   所以它没写进 requirements.txt —— 否则一个装不上的包会把主依赖一起拖垮。
#   项目本身对它有降级处理：装不上就自动用内置的纯 Python 向量库，功能不受影响。
#
# 【实测更新】chromadb 现在可以正常安装（已在本机 Python 3.13.7 上装好 1.5.9）。
#   安装：
#       pip install chromadb
#   或者：
#       pip install -r requirements-chroma.txt
#
#   如果又遇到 from versions: none：
#     1) 先升级 pip 再试：pip install -U pip
#     2) 确认索引源里有 chromadb：pip index versions chromadb
#     3) 换官方源试一次：pip install chromadb -i https://pypi.org/simple
#     4) 都不行就换 Python 3.12 建环境（本机 uv 装过 3.12）：
#          uv venv --python 3.12 .venv312
#          .venv312\Scripts\activate
#          pip install -r requirements.txt -r requirements-chroma.txt
#     5) 或者用 Docker（镜像基于 python:3.11）：docker compose up --build
#
# 装成功后记得：
#   1) 确认 .env 里 VECTOR_BACKEND=chroma
#   2) 删掉旧的内置向量索引 data/memory_index.json（两种实现的向量不能混用）
#   3) 重新导入文档（网页上传 或 python scripts/bulk_ingest.py "目录"）
#   4) 打开 http://127.0.0.1:8000 ，页面顶部应显示「向量库 chroma」（而不是 memory）
#
# 装好后 Chroma 的数据会存在 data/chroma/ 目录（里面能看到 chroma.sqlite3 等文件）。
chromadb>=0.4.24
